# CRM для Школы Танцев

Это CRM система, разработанная для управления школой танцев.

## Требования

*   Python 3.8+
*   pip

## Инструкции по установке и запуску

1.  **Склонируйте репозиторий**
    ```bash
    git clone <URL репозитория>
    cd <имя папки репозитория>
    ```

2.  **Создайте и активируйте виртуальное окружение** (рекомендуется)
    ```bash
    python -m venv venv
    source venv/bin/activate  # Для Windows: venv\Scripts\activate
    ```

3.  **Установите зависимости**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Перейдите в директорию проекта Django**
    ```bash
    cd crm
    ```

5.  **Примените миграции базы данных**
    ```bash
    python manage.py migrate
    ```

6.  **Создайте суперпользователя** (администратора)
    ```bash
    python manage.py createsuperuser
    ```
    Вам нужно будет ввести логин, email и пароль.

7.  **Запустите сервер для разработки**
    ```bash
    python manage.py runserver
    ```

## Доступ к приложению

*   **Панель администратора:** `http://127.0.0.1:8000/admin/`

Войдите, используя данные суперпользователя, которые вы создали на шаге 6.
